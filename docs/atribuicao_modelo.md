# Atribuição da referência de organização

A estrutura de documentação considera o modelo **FIAP — Portfólio 1CCON**, da FIAP, disponível em:
https://github.com/equipe1ccon/FIAP-PORTFOLIO-1CCON/tree/master

O README de exemplo informa licença Creative Commons Attribution 4.0 International:
https://creativecommons.org/licenses/by/4.0/

A organização foi adaptada ao CityWatch, com identificação individual, entrada Python, dados simulados, testes e extensão mobile preservada. Não foi copiado código de solução acadêmica do modelo; o uso é como referência de apresentação. Esta atribuição não concede automaticamente licença sobre todos os assets de terceiros ou sobre todo o código do aplicativo.

# Dados da demonstração acadêmica

CSVs UTF-8, separador vírgula, cabeçalho. Ocorrências: 13 linhas, das quais 12 válidas e OC-013 com descrição ausente. Histórico: dez atualizações fictícias. Bairros genéricos, sem dados pessoais. Arquivos são cópias exatas de `backend/dados/`; um teste impede divergência entre as cargas.

O modo acadêmico não modifica esses CSVs. Sem `--estado`, as operações duram só a sessão. Com `--estado data/estado-local.json`, as alterações são persistidas separadamente. Estados pessoais e bancos do aplicativo não devem ser publicados.

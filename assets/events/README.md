# Ilustrações de eventos

Três imagens criadas em 18/11/2026 pela ferramenta integrada `image_gen`, modo **geração nova** (sem imagem de entrada), usando a skill imagegen. São ilustrações fotográficas geradas por IA; não são registros de eventos reais nem fotografias de locais confirmados. O aplicativo exibe essa identificação.

Os PNGs gerados foram convertidos com `sips` para JPEG, qualidade 80, para uso local no aplicativo, sem nova consulta externa. Os arquivos finais são `assets/events/festival.jpg`, `assets/events/running.jpg` e `assets/events/adoption.jpg`.

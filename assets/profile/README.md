# Avatar demonstrativo

`demo-avatar.png` é a imagem enviada pelo usuário em 19/11/2026 para uso como foto de perfil no protótipo. Foi copiada sem alteração do arquivo fornecido; o recorte circular é feito pela interface.

É um avatar ilustrativo, não verificação de identidade da conta. Uma fotografia escolhida e salva pelo usuário tem prioridade. Nenhuma licença independente ou autoria desta imagem foi presumida: a autorização de uso nesta tarefa veio do usuário; revisar os direitos antes de uma distribuição comercial.
